## Setting a spanned wallpaper

- **Windows:** Settings → Personalization → Background → choose the image → "Choose a fit" → **Span**.
- **macOS:** macOS sets wallpaper per display. Split the image into one slice per monitor, or use a tool such as Multi Monitor Wallpaper.
